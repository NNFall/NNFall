# Profile visual assets

Technology badges were generated through the official [Shields.io static badge API](https://shields.io/badges) and stored in this repository so viewing the profile does not depend on a live badge service.

Badges use the `for-the-badge` style and Simple Icons logo identifiers: python, django, fastapi, postgresql, javascript, typescript, react and docker. Brand names and logos remain the property of their respective owners. These badges indicate technologies used, not certification or affiliation.

The statistical diagrams are generated from GitHub API data. Their scope and limitations are documented separately in the statistics methodology.
